# Project Rules

## Scope
- Do not change the theme, colours, layout or any existing feature unless I explicitly ask for that change in my prompt.
- Only change what the current task needs. Do not touch other code.
- Do not add new libraries or extra files unless really needed.

## Code style
- Keep the code simple and do not over-engineer it.
- Add clear comments in the code so a beginner can understand it.
- Always keep the layout mobile-friendly.

## Workflow
- Before writing any code, first review the existing code, then give me a plan and wait for my approval.
- Do not commit anything. I will commit myself.
- At the end of each task, tell me what changed and how to test it.

## README
- Whenever a feature is added or changed, add or update one line about it in the Features list of README.md.
- Only list features that really work in the app. Do not invent anything.
